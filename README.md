## About

Full-stack software engineer focused on LLM features end to end: prompt design,
production implementation, offline evaluation, safety guardrails and monitoring
after release.

- Ship LLM features on a local-services marketplace: generation behind a pre-send
  quality gate, with a template fallback and a rollback path
- Evaluate output with hand-labeled samples and LLM-as-a-judge in Python
- Build with coding agents through a spec-first, test-first workflow
- Japanese · English · Chinese
